# AURÉLE — Jewellery Website Portfolio Project

A responsive editorial-style jewellery storefront concept built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract `aurele-jewellery-website.zip`.
2. Open the `aurele-jewellery-website` folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and choose **Open with Live Server**.
4. Product images and Google Fonts use online URLs, so an internet connection helps.

## Included interactions
- Responsive mobile navigation
- Product category filters
- Quick-view product modal
- Add-to-bag interactions, quantity count, remove items, subtotal
- Product search
- Newsletter demo form
- Toast notifications

## Before publishing
- Replace the sample product imagery, prices, and brand copy with your own.
- Update the contact email in the footer.
- The cart and newsletter are front-end demos. Connect a backend, email service, and payment provider for real orders.
- Product images are loaded from Unsplash URLs and need internet access.

Built as a portfolio concept project. Brand name: AURÉLE.
